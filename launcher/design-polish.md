# ISLAND 0.10.20 交互与配色改进

使用 frontend-design、ui-ux-pro-max 与 web-design-guidelines。基线截图：`artifacts/version-filter-published/`、`artifacts/version-filter-full-ui/`。

## 方向与取舍

保留原生 WPF 的山林、纸娃娃和紧凑资源列表。主视觉是山林插画，其他界面保持安静；不引入网页式营销区块、渐变背景或额外展示卡片。Segoe UI / Microsoft YaHei UI 继续承担中英文排版，使用 24 / 17 / 14 / 12 / 11 的层级，不额外下载字体。

浅色基准：森林绿 #32634D、海洋蓝 #32699B、背景 #F3F6F4、内容 #FFFFFF、正文 #22352E、辅助文字 #52645C。强调色服务于主要操作、选中与焦点；正文和边框减少随强调色染色。新增苔原青、暮海蓝和完整海岛夜色方案，旧配色与自定义外观保持可选。文字和操作色通过实际对比度计算修正，深色方案覆盖窗口、表单、弹窗和预览，且保存后恢复。

## 交互修正

- 输入提供清晰名称、可见提示与 Ctrl+F；取消使用 Escape 或可见按钮。
- 新搜索保留已有结果，期间阻止安装旧选择；取消后恢复已有结果，失败提供重新搜索操作。
- 选中行使用背景与边缘标识，鼠标悬浮不会覆盖选中态；按钮悬浮保留文字对比度，键盘焦点不改变布局。
- 目录提示优先说明独立 / 共享和下一步，完整路径可查看但不挤占列表空间。
- 保留「全部」默认筛选，资源安装仍按目标实例检查兼容性。

## 适用性复核

UI/UX 技能建议中的自然配色、文字对比度与 WPF 键盘导航适用；营销页 Hero + Features 模板和网页字体组合不适用，未采用。Web Interface Guidelines 中的焦点、加载反馈、空态、命名与长内容规则映射到 WPF 控件与 AutomationProperties，不添加 HTML / ARIA。

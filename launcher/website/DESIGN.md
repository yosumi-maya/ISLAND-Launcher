# 官网设计方向

2026-10-27，使用 frontend-design、ui-ux-pro-max、Sites。原生 HTML / CSS / JS，无前端运行依赖。

主色：云白 #F5F7F7、雾灰 #E8EEEE、深松 #263D38、岛屿青 #287567、海水 #C8DFDA、沙色 #D9C9AA。中文使用系统等线 / 苹方，英文标题使用本地可用的 Trebuchet MS；下载和状态使用相同字体，不引入第三方字体服务。

页面以「一座容纳不同世界的岛」为线索。首屏左侧为简短介绍与下载，右侧用代码原生 SVG 等高线岛屿作为品牌图案；下方的大幅实际界面截图承担产品展示。视觉重点放在岛屿图案与真实截图，不加入虚构评价、用户数量或性能数字。保留白灰背景，避免刺眼黑白。

结构：导航 → 品牌首屏 → 可切换的真实主题截图 → 实例与下载功能 → 外观与地图卡片 → 下载及运行要求 → API 可用性 → FAQ → 隐私及项目链接。手机按内容顺序单栏排列；功能区用开放排版，避免重复卡片墙。

ui-ux-pro-max 的 gaming 搜索命中了紫色电竞与 WebGL 建议。该方案不符合用户偏好的白灰色和轻量 Windows 启动器，因此不采用；保留其键盘焦点、44px 触控、对比度、响应式和减少动效规则。无自动漂浮或滚动动画，只在切换主题、打开截图时响应用户操作。

API 说明区明确区分已实现的登录流程、尚未核实的 Minecraft Services API 资格、尚未接入的 CurseForge API 与已可用的 Modrinth 下载。申请由项目所有者自行提交。

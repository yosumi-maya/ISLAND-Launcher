ISLAND LAUNCHER / DATA & PRIVACY

数据与隐私说明

更新日期：2026 年 10 月 27 日 · 对应启动器版本 0.10.22

这里说明介绍网站与 Windows 启动器如何处理信息，以及哪些操作会访问外部服务。

01 介绍网站02 本机数据03 账号与皮肤04 外部连接05 你的选择
01

介绍网站

本站是静态介绍页面，不提供账号注册、微软登录表单或文件上传。本站代码未集成广告、流量分析、第三方字体或追踪脚本，也不使用 Cookie 或本地存储进行访客追踪。语言选择通过页面 URL 参数保留。

访问网页仍会产生正常的网络请求。网站托管服务可能依据其配置和隐私政策处理 IP 地址、请求时间等网络信息。本说明不代表托管服务完全不产生日志。

下载按钮将跳转到 GitHub Releases。访问 GitHub 时，适用 GitHub 自身的服务条款与隐私政策。

02

启动器在本机保存的数据

启动器会在本机保存游戏目录、实例偏好、收藏、游玩记录、Java 检测记录、运行参数和外观设置。账号信息可能包括玩家名称、UUID、皮肤图像及所用的 Microsoft 应用 ID。

默认配置目录为 %LOCALAPPDATA%\IslandLauncher，也可由启动参数指定独立目录。Java 检测列表存放在同一配置目录下的 java-runtimes.json。游戏、模组和存档位于你选择的游戏目录。

启动器会保存启动诊断与游戏输出日志。游戏和模组可能自行输出其他信息，请在对外分享日志前检查其中的内容。

03

Microsoft 账号与皮肤

Microsoft 登录默认使用系统浏览器授权码 + PKCE，也可切换为设备码。浏览器登录只在授权期间开启本机回环回调；不使用客户端密钥。账号密码在 Microsoft 官方网页输入，启动器不收集 Microsoft 密码。

授权流程会联系 Microsoft、Xbox 与 Minecraft 服务以取得游戏会话及玩家档案。刷新凭据在保存前通过当前 Windows 用户的 DPAPI 加密保护；游戏会话凭据用于本次认证和启动。

同步正版皮肤会读取官方玩家档案。由你主动触发的上传皮肤或恢复默认皮肤操作，会访问 Minecraft 官方接口并修改该账号的皮肤。仅在本地选择预览时，不会自动上传。

当前应用的 Minecraft API 访问资格仍待确认，正版登录及官方皮肤操作的实际可用状态，以后续发布说明为准。
04

下载与外部连接

通过 Modrinth 下载整合包、Mod、资源包、光影，或下载游戏、加载器、依赖与皮肤时，启动器会连接相应的发布服务和内容分发网络。根据你的选择，也可能连接镜像源或整合包相关服务。对方可能依据自身政策处理网络请求信息。

游戏、模组及第三方整合包拥有各自的网络行为和隐私政策，本说明不覆盖这些第三方程序的全部行为。网页功能示意使用虚构实例；实际界面截图由项目所有者提供，并在发布前检查是否包含私人信息。

05

你的选择与项目反馈

你可以在启动器中移除账号、调整实例目录或更改设置，也可以在备份后自行清理本机配置。请区分启动器配置和游戏存档，清理前保留需要的数据。

项目反馈通过公开的 GitHub Issues 提供。请勿在公开问题中上传账号凭据、私人游戏数据或未经检查的日志。

ISLAND Launcher 是非官方项目，与 Mojang Studios 或 Microsoft 无隶属、合作或背书关系。项目许可与所用第三方组件的许可说明随发布包提供。
